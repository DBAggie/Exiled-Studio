Exiled Studio

A build planner for Path of Exile. It works offline, needs no account, and sends nothing about you or your builds anywhere.

Before you install

  • Path of Exile 1. Builds are calculated for Path of Exile 1. Path of Exile 2 calculations are not part of this version.
  • Windows may warn about the installer. It is not code signed, so SmartScreen can say it does not recognise it. Choose More info, then Run anyway. The SHA-256 in the table lets you check the file is the one published here.
  • Updates. The Windows installers and the AppImage offer each new version of their own channel when it is published, and install it only when you agree. The Debian package tells you about it.
  • Game data comes with the installers. The application downloads newer game data by itself when it starts; you can turn every connection off in its settings.
