Exiled Studio

A build planner for Path of Exile. It works offline, needs no account, and sends nothing about you or your builds anywhere.

Before you install

  • Windows may warn about the installer. It is not code signed yet, so SmartScreen can say it does not recognise it. Choose More info, then Run anyway. The SHA-256 in the table lets you check the file is the one published here.
  • Updates. The Windows installers and the AppImage offer each new version of their own channel when it is published, and install it only when you agree. The portable zip and the Debian package tell you about it.
  • Game data comes with the installers. The application can check for newer game data; you can turn every check off in its settings.
